# Сайт ГК «НиАЗ» + мини-CRM

Редизайн com-transport.ru на Next.js (App Router) с сохранением SEO-актива и
встроенным рабочим местом отдела продаж.

## Быстрый старт

```bash
npm install
npx prisma migrate deploy      # схема БД
npx prisma db seed             # стадии, услуги, учётки
npm run dev                    # http://localhost:3000
```

Вход в CRM после наполнения базы: `admin@niaz.ru` / `niaz2026` —
**сменить при первом входе** (Настройки → Смена пароля).

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Подключение к БД. По умолчанию `file:./dev.db` (SQLite) |
| `AUTH_SECRET` | Ключ подписи сессионной куки. **Обязательно свой на бою** |
| `NEXT_PUBLIC_SITE_URL` | Базовый адрес: подставляется в canonical и sitemap |
| `SITE_INDEXABLE` | `true` открывает сайт поисковикам. На тестовом домене не ставить |

Тестовый домен должен запускаться с `SITE_INDEXABLE` не равным `true`:
`robots.txt` тогда закрывает стенд целиком, и он не попадёт в индекс рядом
с боевым сайтом.

## Что где лежит

```
app/(site)/        публичный сайт
  [slug]/          все страницы донора: товар, раздел, статья, индекс раздела
  produktsiya/     корень каталога
  tendery/         деал-рум для госзаказчиков
app/crm/           CRM: (dash) — рабочие экраны, login — вход
app/api/lead/      приём заявок с форм сайта
lib/catalog.ts     структура каталога и меню (правки заказчика — здесь)
lib/content.ts     доступ к собранной модели контента
data/donor/        сырая выгрузка com-transport.ru
data/content/      модель контента, из которой собирается сайт
prisma/            схема БД, миграции, наполнение
scripts/           выгрузка донора, сборка контента, проверки
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` / `build` / `start` | обычный цикл Next.js |
| `npm run scrape:donor` | выгружает WP REST донора в `data/donor/` |
| `npm run scrape:html` | забирает отрендеренный HTML: 202 страницы собраны конструктором, REST по ним пуст |
| `npm run build:content` | превращает выгрузку в модель контента и карту 301 |
| `npm run check:urls -- <адрес>` | приёмочный краулинг §6.1: все 327 URL донора |
| `npm run smoke -- <адрес>` | сквозная проверка: заявка, защита CRM, sitemap |
| `npm run db:inspect` | что сейчас в базе |
| `npm run clean:test-leads` | убрать заявки, созданные `smoke` |

Порядок при обновлении контента: `scrape:donor` → `scrape:html` →
`build:content` → `build`.

## SEO-миграция

Требование §6.1 ТЗ — **URL 1:1**. Реализовано так:

- слаги страниц не меняются, адреса остаются со слэшем на конце
  (`trailingSlash: true`) — как их проиндексировали;
- снятый раздел «Автобусы» (64 адреса) уходит **301** на ближайшую живую
  линейку, архивы WordPress `/category/*` и `/author/*` — тоже;
- цепочек `A→B→C` нет: короткие алиасы (`/asmp`) ведут сразу на канонический
  адрес, а цели редиректов — канонические, не алиасы;
- `sitemap.xml` перечисляет только адреса, отдающие 200;
- у товарных страниц есть JSON-LD `Product`, у всех — микроразметка
  `BreadcrumbList`;
- meta description генерируется: у донора его нет на 250 страницах из 327.

Состояние приёмки на момент сборки:

```
Проверено URL: 327
  200 напрямую: 262
  через 301: 65
  битых (404/5xx): 0
  цепочек длиннее одного шага: 0
```

Проверять после каждой правки контента или редиректов:
`npm run build && npm run start` и в другом окне `npm run check:urls -- http://localhost:3000`.

## Открытые вопросы к заказчику

1. **Какие базы в каталоге.** На доноре продукция построена на европейских
   шасси (VW Crafter, Mercedes Sprinter, Peugeot Boxer, Renault Master,
   Citroen Jumper), а единственная свежая новость — от 15.01.2024 — сообщает
   о переходе на DONGFENG и FOTON. Сейчас в каталоге лежит контент донора.
   Если линейка сменилась, менять нужно содержимое `data/content/products.json`,
   а адреса страниц оставлять прежними.
2. **Статьи про автобусы.** 15 материалов «Информационного раздела» посвящены
   автобусам («как выбрать туристический автобус» и подобные). Они оставлены
   доступными: это инфо-трафик, а не витрина снятой продукции. Если их тоже
   убирать — добавить слаги в `REMOVED_LANDING_SLUGS` в `scripts/build-content.ts`.
3. **Документы для деал-рума.** Раздел «Тендерам» размечен, но PDF-файлов у
   завода в открытом доступе нет — сейчас они помечены «по запросу».
4. **Фотографии.** Изображения тянутся с com-transport.ru по внешним ссылкам.
   Перед боем их нужно перенести к себе, иначе сайт зависит от старого хостинга.
